# אנטיגרוויטי באנדרואיד 2.0

חדש: Antigravity רץ ישירות בטלפון. לחיצה על "התקנת agy" מורידה את גרסת האנדרואיד הרשמית של Antigravity CLI מבית Google ומאמתת אותה. "הפעלת Antigravity" פותח אותה בטרמינל מובנה, עם מקשי ESC, ‏TAB, ‏CTRL וחיצים, סשנים מרובים והרצה ברקע. ההתחברות ל־Google נפתחת ב־Chrome. החיבור מרחוק למחשב (Remote Control) עדיין זמין.
