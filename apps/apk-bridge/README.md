# APK Bridge

אפליקציית Android עצמאית להתקנת APK מקומית באמצעות Android Wireless Debugging / ADB, ללא Root, מחשב או Termux לאחר ההגדרה.

- Android 11 ומעלה (API 30+).
- Pairing באמצעות קוד Wireless Debugging ו־TLS/SPAKE2.
- זהות ADB נשמרת באחסון הפרטי של האפליקציה.
- קבלת קובצי APK דרך ACTION_VIEW / ACTION_SEND ובחירה מתוך האפליקציה.
- התקנה דרך ADB Package Manager.
- בנייה וחתימה באמצעות תהליך APK Factory הקיים.

הערה: התקנה באמצעות ADB נשארת התקנת ADB. לא ניתן להפוך אותה להתקנה שבוצעה בפועל דרך Google Play או להבטיח שכל Android/אפליקציה תציג אותה כך.
