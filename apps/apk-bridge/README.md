# APK Bridge

אפליקציית Android עצמאית להתקנת APK באמצעות Android Wireless Debugging / ADB, ללא Root, מחשב או Termux.

- Android 11 ומעלה (API 30+).
- **זיווג דרך התראה:** האפליקציה מאתרת לבד את חלון "התאמת מכשיר עם קוד התאמה" (mDNS) ומבקשת את הקוד בשדה תשובה בהתראה, כך שלא צריך לצאת ממסך ההגדרות (יציאה ממנו מבטלת את הקוד).
- **זיווג אוטומטי בנגישות:** שירות נגישות (רק במסכי ההגדרות) מזהה את קוד הזיווג והפורט ומזווג לבד, ושומר גם את פורט החיבור.
- הצעה לפתוח אפליקציה מיד אחרי ההתקנה (חלון או התראה), תצוגה מקדימה של גרסה, עדכון או שנמוך, והתקנה אוטומטית של קובץ שנפתח או שותף.
- יומן בראש המסך, סגור כברירת מחדל.
- **מסך הגדרות:** התקנה אוטומטית (כבוי / לשאול / מיד, ואפשרות לרק עדכונים), פתיחה אחרי התקנה, אפשרויות התקנה, זיווג אוטומטי, הדלקה אוטומטית של ניפוי באגים ושכחת זיווג.
- זיווג ידני, כולל זיווג מול מכשיר אחר באותה רשת.
- חיבור ל־`127.0.0.1` עם איתור אוטומטי של פורט החיבור ושמירת הפורט האחרון שעבד.
- התקנת APK בודד, כמה APK יחד, וחבילות **APKS / XAPK / APKM** (Split APKs), כולל העתקת קובצי OBB של XAPK.
- סינון אוטומטי של חלקי ABI שלא מתאימים למעבד של המכשיר.
- אפשרויות התקנה: שנמוך גרסה (`-d`), הענקת הרשאות (`-g`), חבילות בדיקה (`-t`), עקיפת חסימת targetSdk נמוך ב־Android 14+, ורישום Google Play כמקור ההתקנה (`-i`).
- הסרת אפליקציות (עם/בלי שמירת נתונים) ופתיחת האפליקציה שהותקנה.
- הפעלה אוטומטית של ניפוי באגים אלחוטי: לאחר הענקת `WRITE_SECURE_SETTINGS` דרך ADB מתוך האפליקציה, היא מדליקה את ניפוי הבאגים האלחוטי בעצמה כשהוא כבוי.
- יומן פעולות מפורט עם העתקה, והסברים בעברית לשגיאות התקנה נפוצות.
- הפעולות רצות ברמת התהליך, כך שסיבוב מסך או מעבר לאפליקציה אחרת לא מבטלים התקנה.

## מקור התקנה

כשהאפשרות מסומנת, האפליקציה מבקשת מ־Package Manager לרשום `com.android.vending` כ־installer באמצעות `-i`, ואז בודקת את התוצאה. זו אינה התקנה שבוצעה בפועל מתוך Google Play: Android עשוי להציג את ה־installer הרשום כך, אך initiating package נשאר ADB והאפליקציה אינה מקבלת רישוי, רכישה או אימות Play.

## בנייה

הפרויקט נבנה ב־APK Factory עם מפתח החתימה הקבוע של המאגר. ה־workflow מאמת שה־APK יחיד, לא ריק, חתום, ושה־manifest תואם לגרסה לפני פרסום.
