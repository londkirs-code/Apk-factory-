# פתק צף

אפליקציית Android פשוטה לפתיחת פתק יחיד מעל אפליקציות אחרות.

- גודל החלון קבוע: 300×240dp.
- הטקסט נשמר אוטומטית במכשיר.
- גרירה מתבצעת רק דרך הפס העליון.
- לחיצה על X או הפעלה נוספת של אייקון האפליקציה סוגרת את הפתק.
- בהרצה הראשונה יש לאשר הרשאת הצגה מעל אפליקציות אחרות.

הבנייה מתבצעת דרך workflow הכללי של APK Factory; קובץ ה־APK מתפרסם ב־downloads/ptak-tsaf/app.apk.
