# שרת שיתוף הרשימות של משנת אוסף

השרת הוא קובץ `Code.gs` שרץ ב-Google Apps Script ושומר את הרשימות בגוגל שיט.

## מה הוא עושה
- **העלאה:** כל רשימה שמועלית מקבלת מספר אקראי פנוי בין 1 ל-1000, ונשמרת 7 ימים.
- **הבאה:** כל אחד יכול להביא רשימה לפי המספר שלה.
- **אין דריסה:** העלאה תמיד יוצרת מספר חדש, כך שאי אפשר לדרוס רשימה של מישהו אחר.
- **מה נשמר:** רק המוצרים (שם, כמות, הערה, מחלקה וקישור לתמונה). שמות חשבונות ומשפחות לא נשלחים.
- **הגבלות:** עד 15 העלאות מכל מכשיר בכל 6 שעות, ועד 1000 מוצרים לרשימה.

## התקנה (פעם אחת)
1. פותחים גיליון חדש ב-Google Sheets, למשל בשם "משנת אוסף - ענן".
2. בתפריט: **תוספים ← Apps Script**.
3. מוחקים את כל מה שכתוב בעורך ומדביקים את כל התוכן של `Code.gs`. שומרים (Ctrl+S).
4. בוחרים בפונקציה `setup` בשורת הכלים ולוחצים **הפעלה**. מאשרים את ההרשאות שגוגל מבקשת.
   - אם מופיע "Google hasn't verified this app", לוחצים Advanced ← Go to ... (unsafe). זה תקין, כי זה הסקריפט שלך.
   - הפעולה יוצרת לשונית `lists` עם 1000 שורות, ומתזמנת ניקוי יומי.
5. **פריסה ← פריסה חדשה**:
   - סוג: **אפליקציית אינטרנט (Web app)**
   - הפעלה בתור: **אני**
   - למי יש גישה: **כל אחד (Anyone)**
6. מעתיקים את **כתובת אפליקציית האינטרנט**, שמסתיימת ב-`/exec`.
7. בודקים: פותחים את הכתובת בדפדפן. אמור להופיע `{"ok":true,"service":"mishnat-pickup-cloud",...}`.
8. את הכתובת מכניסים לאפליקציה: **הגדרות ← ייבוא ונתונים ← כתובת שרת הענן**. אפשר גם לשלוח אותה לClaude, והיא תיכנס לאפליקציה כברירת מחדל לכל המשתמשים.

## עדכון קוד בעתיד
אחרי שינוי בקוד: **פריסה ← ניהול פריסות ← עריכה (עיפרון) ← גרסה: גרסה חדשה ← פריסה**. כך הכתובת נשארת אותה כתובת.

## מבנה הגיליון
יש שורה קבועה לכל מספר, מ-1 עד 1000. בכל שורה:
- זמן יצירה
- זמן פקיעת תוקף
- שם הרשימה
- מספר המוצרים
- גיבוב של מזהה המכשיר (לא המזהה עצמו)
- תוכן הרשימה, ב-4 עמודות לכל היותר

שורה שפג תוקפה נחשבת פנויה מיד, וגם מתרוקנת בניקוי היומי.
