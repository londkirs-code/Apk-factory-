# משנת אוסף – הורדה לאפליקציה (תוסף ל-Chrome ול-Firefox)

התוסף מוסיף לאתר משנת יוסף כפתור **"📥 לאפליקציה"**. בוחרים הזמנה אחת או כמה (עד 20), בוחרים פורמט, ומורידים קובץ שנפתח באפליקציה משנת אוסף **גם בטלפון בלי אינטרנט**.

## הפורמטים
- **טקסט (TXT):** קובץ קטן וקריא. שורה "## שם" לפני כל הזמנה, ואחריה שורה לכל מוצר: `שם | כמות | | הערה | קטגוריה`. בלי תמונות.
- **JSON:** הפורמט המלא של האפליקציה (`mishnat-pickup-list`), עם קישורים לתמונות. התמונות נטענות אחר כך רק כשיש אינטרנט.
- **ZIP עם תמונות:** קובץ `list.json` ותיקיית `images` עם תמונות המוצרים, כך שהן מוצגות גם בלי אינטרנט.

**בטלפון:** מעבירים את הקובץ (בכבל, בבלוטות' או בכרטיס זיכרון), ואז באפליקציה בוחרים "רשימה חדשה" ← "ייבוא מקובץ".

## התקנה
**Chrome / Edge:**
1. מורידים את `mishnat-osef-chrome-<גרסה>.zip` ופותחים אותו לתיקייה.
2. נכנסים ל-`chrome://extensions` ומדליקים "מצב מפתח" (Developer mode).
3. לוחצים "טעינת פריט לא ארוז" (Load unpacked) ובוחרים את התיקייה.

**Firefox:**
- **לבדיקה:** נכנסים ל-`about:debugging#/runtime/this-firefox`, לוחצים "Load Temporary Add-on" ובוחרים את קובץ ה-ZIP. התוסף נשאר רק עד שסוגרים את Firefox.
- **התקנה קבועה:** Firefox רגיל מתקין רק תוסף חתום. מעלים את `mishnat-osef-firefox-<גרסה>.zip` ל-[addons.mozilla.org](https://addons.mozilla.org/developers/) כ"לא רשום" (Unlisted), ומקבלים קובץ חתום להתקנה. אפשרות אחרת: Firefox Developer Edition או ESR עם `xpinstall.signatures.required=false`.

## פרטיות והרשאות
- **התחברות:** משתמשים בהתחברות שהאתר עצמו שמר בדפדפן. היא לא נשמרת בתוסף ולא נשלחת לשום מקום חוץ מהשרת של משנת יוסף.
- **הרשאות:** גישה רק ל-`v2.mishnatyosef.org`, שם נמצאות ההזמנות, ול-`images.mishnatyosef.org`, שם נמצאות התמונות ל-ZIP.
- **מה יש בקובץ:** רק מוצרים, כמויות, קטגוריות ותמונות. בלי שם, כתובת, טלפון או פרטי תשלום.
- **מעקב:** אין איסוף נתונים, אין אנליטיקה ואין פרסומות.
- **מעמד:** התוסף לא רשמי ואינו קשור למשנת יוסף.

## פיתוח
- `src/core.js`: פענוח ההזמנה וייצוא הקבצים. זה העתק של OrderParser ו-ListExporter באפליקציה, וכל שינוי בפורמט צריך להיעשות בשני המקומות.
- `src/content.js`: הכפתור והחלון באתר.
- `src/background.js`: הורדת התמונות ל-ZIP, ולחיצה על סמל התוסף.
- `manifest.base.json`: ההגדרות המשותפות. `build.mjs` יוצר ממנו גרסה ל-Chrome (service worker) וגרסה ל-Firefox (background script ו-gecko id).
- **בדיקות:** `node --test test/core.test.mjs`. יצירה מחדש של קובצי הדוגמה אחרי שינוי מכוון: `node test/fixtures.mjs --write`.
- **תאימות לאפליקציה:** הבדיקה `ExtensionCompatibilityTest` באפליקציה מייבאת את `test/fixtures/export.*`. אם הפורמט נשבר, הבנייה נכשלת.
- **בנייה:** `node build.mjs <תיקייה>` יוצר `mishnat-osef-chrome-<גרסה>.zip` ו-`mishnat-osef-firefox-<גרסה>.zip`. בכל בנייה של ה-PR ושל main הם נוצרים אוטומטית ומקושרים בהודעה.
