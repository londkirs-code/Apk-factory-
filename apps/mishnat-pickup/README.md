# משנת יוסף — רשימת איסוף

אפליקציית Android עצמאית שמתחברת לחשבון משנת יוסף ומציגה רק את ההזמנה העדכנית ביותר כרשימת איסוף עם תמונות.

## התנהגות
- התחברות בדף הרשמי של משנת יוסף; ניתן לבחור אימייל וסיסמה או כניסה באמצעות קוד חד־פעמי ב־SMS.
- לאחר ההתחברות נטענת ההזמנה העדכנית ביותר שאינה מבוטלת מתוך `GET /api/orders`, ואחריה פרטיה מ־`GET /api/orders/{id}`.
- מבנה המוצרים מבוסס על תוסף CRX 6.2: `order.products`, `order.items`, `item_salesID`, `featured_image`, `full_name` ו־`amount`.
- תמונות המוצרים נטענות מ־`https://images.mishnatyosef.org/images/items/{featured_image}`.
- כל כרטיס המוצר לחיץ. לחיצה מסמנת את המוצר כנאסף, מעבירה אותו מיד לתחתית הרשימה ומגלילה לאזור ״נאספו״. לחיצה חוזרת מחזירה אותו לממתינים.
- סימוני האיסוף נשמרים מקומית לפי מזהה הזמנה. סימון אינו משנה את ההזמנה באתר.
- רק טוקן הגישה נשמר מוצפן ב־Android Keystore. סיסמה או קוד SMS אינם נשמרים.

## בנייה
המקור נשמר בארכיון `build-sources/mishnat-pickup.tar.gz` במאגר APK Factory ונפרס לתיקיית `apps/mishnat-pickup` בזמן בנייה. בנייה דרך workflow ייעודי `Build Mishnat Pickup APK`.
