# יומן שינויים — netz

## 2026-10-19 — שיפור תאימות Android

- הורד minSdk ל־21 (Android 5.0) לאחר בדיקת שימושי API, כדי להרחיב תמיכה גם למכשירים ותיקים.

- הועלה target SDK ל־35 כדי לבדוק ולהתאים את האפליקציה להתנהגות Android חדש.
- הותאמו אזורי התוכן לסרגלי המערכת ולחיתוכי מסך ב־Android 15 ומעלה.
- תוקן טיפול בהרשאת מיקום כך שגם הרשאת מיקום מקורב תזוהה, והבקשה ל־WebView תושלם לאחר תשובת המשתמש.
- הוגבלו גישה מקובץ לקובץ ותוכן מעורב ב־WebView, ונוספו שמירה ושחזור מצב וניקוי משאבים בסגירה.
- לא שונה קובץ ה־HTML או התוכן/העיצוב של האפליקציה.

## 2026-10-19 — יצירת אפליקציית נץ

- **בקשה/מטרה:** להפוך את קובצי נץ.html ונץ.txt שבדרופבוקס לאפליקציית Android דרך APK Factory.
- **קבצים ונקודות בקוד:** נוצר פרויקט apps/netz עם MainActivity, AndroidManifest, Gradle וקובץ HTML מוטמע ב-assets.
- **השינוי בפועל:** אפליקציית WebView מקומית הכוללת שעון, ספירה לאחור לזריחה, מיקום, צליל והגדרות זווית ותיקון זמן. התוכן נבנה מחדש על בסיס הטקסט שניתן לחלץ מהקובץ; כלי החילוץ של Dropbox לא החזיר את ה-CSS וה-JavaScript המקוריים.
- **מה נשמר ללא שינוי:** לא שונו קבצים של אפליקציות אחרות.
- **בדיקות שבוצעו:** נבדק שהקבצים המקוריים קיימים ושווים בגודל ובטביעת התוכן. בניית APK עדיין דורשת הצלחת GitHub Actions.
- **תוצאת בנייה / APK:** ממתין לבנייה בענן.
