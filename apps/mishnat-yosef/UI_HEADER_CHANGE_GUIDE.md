# תיעוד שינוי הכותרות — משנת יוסף

## מטרת השינוי
- להסיר מכל המסכים את שורת שם האפליקציה הקבועה `משנת יוסף` שמופיעה בראש המסך.
- להשאיר את כותרת המסך הנוכחי (לדוגמה: `היסטוריית הזמנות`, `זיכויים וחיובים`, `התחברות לחשבון`) אך להקטין את גודל הטקסט בחצי: מ־18sp ל־9sp.
- לצמצם את הריווח האנכי של הפס העליון מ־8dp ל־4dp, גם בפריסה הרגילה וגם בעת התאמת Insets של Android, כדי שהאזור העליון יהיה נמוך יותר.
- לא לשנות את שמות המסכים, הניווט, פעולות המסכים או תוכן העמודים.

## היכן משנים בקוד
קובץ:
`apps/mishnat-yosef/app/src/main/java/org/mishnatyosef/mobile/MainActivity.java`

נקודת הכניסה המשותפת:
`beginScreen(String heading, int tab, Runnable back)`

הפונקציה `beginScreen` בונה את המסגרת העליונה המשותפת למסכים. לכן שינוי שם משפיע על כל המסכים שנבנים באמצעותה, ולא דורש עריכה נפרדת במסך ההיסטוריה, במסך הזיכויים ובמסכים אחרים.

## מה השתנה
1. הוסרה יצירת ה־`TextView app` שמציג `משנת יוסף`, וכן הוספתו לפריסת הכותרת.
2. כותרת המסך `head` נשארה, אבל גודל הטקסט השתנה מ־`18` ל־`9`.
3. הכותרת הוכנסה ישירות לשורת הכותרת במקום פריסה אנכית שמכילה שתי שורות.
4. הריווח העליון והתחתון של `header` השתנה מ־`dp(8)` ל־`dp(4)`.
5. אותו שינוי ריווח בוצע גם ב־`headerFinal.setPadding(...)` בתוך `setOnApplyWindowInsetsListener`. חשוב לעדכן את שני המקומות, אחרת התאמת אזורי המערכת באנדרואיד עלולה להחזיר את הגובה הישן.

## איך לשמר את השיטה לשינויים דומים
1. **לאתר רכיב משותף:** חפשו פונקציה אחת שבונה את הממשק החוזר, כמו `beginScreen`, במקום לשנות כל מסך בנפרד.
2. **לבדוק את כל מופעי הרכיב:** חפשו יצירה של הכותרת, הוספתה לפריסה, וריווחים שמתעדכנים שוב ב־Insets.
3. **לבצע שינוי ממוקד:** החליפו רק את הקטעים הדרושים. לפני עדכון אוטומטי, ודאו שהקטע הישן מופיע בדיוק פעם אחת כדי למנוע החלפה שגויה.
4. **לשמור תיעוד לצד הפרויקט:** ציינו את הקובץ, שם הפונקציה, הערכים לפני ואחרי, ואת הדברים שאסור לשנות.
5. **לבנות ולבדוק:** להריץ את GitHub Actions של בניית ה־APK, לוודא שהבנייה הצליחה, ואז לבדוק במכשיר מסכים שונים — כולל מסכים עם כותרת ארוכה, מסכי התחברות, היסטוריה וזיכויים.
6. **לא להסתפק בקומפילציה:** קומפילציה תקינה מוכיחה שהקוד נבנה, אבל לא מוכיחה שהגובה, היישור והטקסט נראים טוב בכל המסכים.

## רשימת בדיקה לשינוי הזה
- [ ] שורת `משנת יוסף` אינה מוצגת בכותרת העליונה באף מסך.
- [ ] כותרת המסך הנוכחי עדיין מוצגת.
- [ ] גודל כותרת המסך הוא 9sp במקום 18sp.
- [ ] הריווח האנכי הוא 4dp גם לפני וגם אחרי התאמת Insets.
- [ ] כפתור החזרה (במסכים שבהם הוא קיים), סרגל הניווט ותוכן המסך ממשיכים לעבוד.
- [ ] GitHub Actions הסתיים בהצלחה וה־APK החדש נוצר.

## הערת תחזוקה
אם בעתיד רוצים לשנות שוב את עיצוב הכותרת, מתחילים ב־`beginScreen`. אם מסך מסוים נבנה בדרך אחרת ואינו משתמש בפונקציה הזאת, יש לאתר אותו בנפרד לפני שמניחים שהשינוי המשותף מכסה אותו.
