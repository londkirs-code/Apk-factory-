# תיקון רענון רשימת המכירות הפתוחות

- בקשות לרשימת המכירות הפתוחות עוקפות מטמון באמצעות כתובת ייחודית וכותרות למניעת מטמון, כדי שהעמוד יקבל את המצב העדכני לאחר התראת מכירה חדשה.
- מנגנון ההתראות משתמש באותה הגנה מול מטמון בזמן בדיקת המכירות.
- לא שונתה לוגיקת ההזמנות, ההתראות או הצגת כרטיסי המכירה.
