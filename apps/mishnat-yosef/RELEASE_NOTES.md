# סגירת תמונה מוגדלת בלחיצה מחוץ לתמונה

- תוקן אזור הלחיצה סביב התמונה המוגדלת, כך שלחיצה מעל התמונה או מתחתיה סוגרת אותה, כמו לחיצה בצדדים.
- נשמרת האפשרות ללחוץ על התמונה עצמה בלי לסגור אותה, ולסגור באמצעות כפתור ה־× שעל התמונה.
- הותאם אזור התמונה למידות המסך כדי שטיפול בלחיצות יהיה עקבי גם בשטחים הריקים שמסביב לתמונה.
