# ניהול רשימות TaskHub — עריכה ומחיקה

- נוספה אפשרות לפתוח תפריט ניהול לכל רשימה במרכז המשימות.
- ניתן לערוך את שם הרשימה ואת התיאור שלה בלי לפגוע במשימות הקיימות.
- נוספה מחיקה לצמיתות של רשימה, עם אישור מפורש והודעה שמבהירה שגם המשימות, המצבים האישיים והיסטוריית הפעולות יימחקו.
- מחיקת הנתונים מתבצעת בסדר ששומר על קשרי המפתחות הזרים, והרשאות מנהל ייעודיות נאכפות ב־Supabase RLS.
