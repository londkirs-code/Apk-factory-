# התראה קבועה לשיפור קבלת עדכונים

- נוספה בראש הגדרות ההתראות אפשרות להפעיל התראה מתמשכת בשם «משנת יוסף».
- תוכן ההתראה משתנה לפי ההתראות הפעילות בפועל: פתיחת מכירה, תזכורת לפני סגירה ועדכוני מוצרים שאזלו או חזרו למלאי.
- בעת הפעלת אחד מסוגי ההתראות הרלוונטיים, אם ההתראה הקבועה כבויה תופיע המלצה עם קיצור דרך להגדרתה.
- ההתראה מסייעת להשאיר את פעילות ההתראות גלויה, אך אינה מבטיחה שמערכת Android או הגדרות חיסכון בסוללה לא יגבילו פעילות ברקע.
