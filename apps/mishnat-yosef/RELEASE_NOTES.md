# תיקון החלפת צבע לכל פסי ההזזה וההתקדמות

- פסי ההזזה בהגדרות התצוגה מתעדכנים מיד כשמחליפים בין ערכת הכתום לערכת הסגול.
- צבע הידית והפס הפעיל נלקח מהערכת הנושא הפעילה; מסילת הרקע מתאימה לצבעי הממשק.
- הוגדר כלל מרכזי אחד לכל רכיבי פסי ההזזה ומדדי ההתקדמות, במקום לטפל בכל פס בנפרד.
- התיקון חל גם על רכיבי פס שכבר נוצרו במסכים פתוחים, בלי לבנות מחדש את המסך או לשנות את פעולת הפקדים.
