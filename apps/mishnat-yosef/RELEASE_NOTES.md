# זיהוי עדכונים חדש מגיטהאב

- בדיקת הגרסה מול GitHub מבקשת כעת בכל פעם מידע עדכני ללא שימוש בעותק שמור של קובץ העדכון.
- כך האפליקציה יכולה לזהות פרסום חדש גם כאשר שכבת המטמון של GitHub עדיין מחזיקה עותק קודם של קובץ המידע.
- הורדת ה־APK ממשיכה להתבצע עם כתובת ייחודית ואימות SHA-256 לפני הצגת אפשרות ההתקנה.
