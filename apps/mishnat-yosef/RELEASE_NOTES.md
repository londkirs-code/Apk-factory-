# תיקון סדר הקטגוריות במכירות

- הקטגוריות מוצגות לפי סדר הופעת המוצרים ברשימה שהשרת מחזיר, במקום מיון אלפביתי כשאין דירוג קטגוריה זמין.
- אותו כלל חל על מכירה פעילה ועל מכירה שנפתחת מהמטמון המקומי, ששומר את סדר המוצרים המקורי.
- נשמר מיון שמות המוצרים בתוך כל קטגוריה; השינוי נוגע לסדר הקטגוריות בלבד.
