- לאחר פתרון אתגר, הנעילה נשארת פתוחה עד חמש דקות גם אם יוצאים מהאפליקציה.
- חמש טעויות רצופות באתגר תמונה או חשבון מפעילות חסימה של חמש דקות, הנשמרת גם לאחר הפעלה מחדש.
- הפעלה וכיבוי של נעילת הילדים מאפסים את זמן הפתיחה ומונה הטעויות.

# תיקון טעינת תמונות בהזמנה

- חיפוש לפי מזהה מידה מאתר את מוצר האב שמכיל את נתוני התמונה.
- פרטי שורת המידה נשמרים בפעולות העריכה כדי לא לבלבל בין מזהי מידות.
- הוספנו ניסיון חוזר יחיד להורדת תמונה שנכשלה בטעינה הראשונה.

# ייצוא כל פרטי המכירה והקטלוג

- בתפריט עמוד ההזמנה נוספה האפשרות „🗂 ייצוא כל פרטי המכירה וכל המוצרים”.
- הקובץ כולל פרטי מכירה מלאים ורשימה מלאה של מוצרי הקטלוג שנטענו, ולא רק את הפריטים שבעגלת ההזמנה.
- נשמרים אובייקטי המוצרים המקוריים מה־API, לרבות שדות נוספים, פרטים מקוננים, וריאציות/מידות ונתוני תמונות.
- אפשרות ייצוא ההזמנה הקיימת ממשיכה לייצא רק את תוכן ההזמנה, ללא שינוי.

# תיקון מגבלות כמות בפריטי לבוש

- נאכפות מגבלות הכמות בעת בחירת מידות לבגדים, כדי למנוע הזמנה מעבר לכמות המותרת.
- השינוי ממוקד בפריטי לבוש עם בחירת מידה ואינו משנה את זרימת ההזמנה של מוצרים רגילים.

- תאימות למכשירים ישנים: בחירת המידה משתמשת בממשק callback פנימי, ללא תלות ב־`java.util.function`.
- תיקון זיהוי מוצרים כשהמזהה נמצא בתוך `product`.
- נוספה בחירת מידה לפריטים שמכילים וריאציות מידה מזוהות; ההזמנה משתמשת במזהה שורת המידה ומסכמת את הכמויות והמחירים שלה.

- תוקנה בדיקת קדם־בנייה: תיעוד הגרסה נכלל באותו commit עם שינויי קוד כדי למנוע חסימת build.
- אבחון עמודי מוצרים: מספר אבות, מערכים מקוננים, אורך גוף ופענוח JSON נרשמים ביומן בדיקות ה־API.
- עמוד ריק או מבנה JSON לא מוכר אינו נבלע בשקט; יש עד שלושה ניסיונות לעמוד ריק, עם פירוט הכשל.
- בדיקת total אינה משווה בין מספר שורות השרת למספר מוצרי האב כשמטא־נתוני העימוד זמינים.

- לחיצה על כתובת API שמורה פותחת חלון עריכה עם הנתיב ומונחי הסינון ששויכו אליה; ניתן לשנות את שניהם לפני ההרצה.
- מונחי סינון נשמרים בנפרד לכל כתובת שמורה. שינוי נתיב מחליף את הרשומה הישנה, ומחיקה מסירה גם את הסינון המשויך.

# שיפור בדיקות API בהגדרות

- העברת אפשרות הכתובת הידנית לראש הרשימה.
- שמירת נתיבים ידניים שהורצו ושילובם ברשימת הכתובות הקיימת.
- שדה סינון באותו חלון של הזנת הנתיב, עם אפשרות להריץ עם סינון או בלעדיו.
- כפתורי ✕ לניקוי שדות קלט ומחיקה אמיתית של נתיבים ידניים שמורים; הנתיבים נשמרים אחרי הרצה מוצלחת ונמחקים גם מהאחסון המקומי בעת מחיקה מהרשימה.
- נשמרו ההגבלות הקיימות: נתיבים יחסיים שמתחילים ב־`/api/`, בקשות GET בלבד והסתרת מידע רגיש לפני העתקת התוצאה.
