# תיקוני מקלדת, מיקוד ותצוגה

- מקשי 1 ו־3 לגלילה רציפה, ומקשי 2 ו־8 לקפיצה לראש ולתחתית, זמינים כעת גם במסכים נוספים ולא רק בעמוד ההזמנה.
- נוספה מסגרת מיקוד ברורה לכפתורים ולפקדים, כולל פלוס, מינוס והוספה להזמנה, כדי שיהיה קל לראות מה מסומן במקלדת.
- תוקן שימור המיקוד לאחר שינוי כמות במוצרים, כדי שהבחירה לא תקפוץ לפתע לכפתור או למיקום אחר.
- תוקנה תצוגת התמונה המוגדלת כך שאזור המגע מכסה את המסך כולו; לחיצה בשטח הריק מעל התמונה ומתחתיה סוגרת אותה, לצד הסגירה באמצעות ×.
- עוצב מחדש אזור הגדרות התצוגה ככרטיס הגדרות עם מסגרת והסבר, בהתאמה לכרטיסים האחרים בחשבון.
