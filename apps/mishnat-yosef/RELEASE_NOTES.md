# פתיחת כרטיס המוצר מהתראת חזרה למלאי

- לחיצה על התראה על מוצר שחזר למלאי פותחת את המכירה המתאימה וממקמת את הרשימה בכרטיס המוצר המדויק.
- נפתח כרטיס המוצר הרגיל של ההזמנה, עם הפרטים והפעולות הקיימות כגון מועדפים, בחירת כמות והוספה להזמנה.
- הניווט משתמש במזהי המכירה והמוצר, טוען את הנתונים העדכניים ושומר את יעד ההתראה גם אם צריך להתחבר מחדש.
