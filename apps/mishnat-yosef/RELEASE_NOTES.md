# 🎉 עדכוני מסך, חיפוש ושיפור בדיקת גרסה

- כפתור ההגדרות העגול בכותרת הראשית הוקטן בחצי תוך שמירה על פעולת פתיחת ההגדרות.
- שורת החיפוש במסך זיכויים וחיובים הועברה אל מתחת לכל כפתורי הפעולות והסינון, ומופיעה מיד לפני רשימת התנועות.
- כשבדיקת GitHub מזהה גרסה חדשה יותר מהגרסה המותקנת, מוצגת הודעה גדולה, שמחה ובצבע ירוק חיובי; מצב זה מוצג רק כאשר אכן קיימת גרסה חדשה.
- פתיחת מסך „עדכוני אפליקציה” מתחילה מיד בדיקה מול GitHub, בלי צורך ללחוץ על כפתור הבדיקה.
- נשמרו מנגנוני ההורדה, אימות SHA-256, ההתקנה והסינון הקיימים.
