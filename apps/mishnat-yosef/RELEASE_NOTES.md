# שיפור עדכון ידני וסנכרון גרסה

- כפתור „עדכון ידני עכשיו” בודק מחדש את פרטי הגרסה מול GitHub בכל לחיצה, במקום להסתמך על מידע ישן שנשמר במכשיר.
- כשיש גרסה חדשה יותר, מתחילה הורדה מאובטחת ואימות SHA-256; ההתקנה נשארת באישור המשתמש דרך Android.
- אם המכשיר כבר מעודכן, הכפתור מציג את הגרסה העדכנית בלי להוריד APK מיותר. לא מבוצעת התקנה לאחור אם GitHub מציג גרסה ישנה יותר.
