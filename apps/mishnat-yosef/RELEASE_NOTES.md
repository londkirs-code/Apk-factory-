# תיקון טעינת זיכויים וחיובים

- טעינת היסטוריית הזיכויים והחיובים תומכת במבני התשובה השונים של השרת, כולל מערך ישיר ומעטפות נתונים מקוננות.
- שופרה קריאת נתוני העימוד כדי לא להפסיק אחרי העמוד הראשון כאשר השרת מחזיר פרטי pagination במבנה חלופי.
- בקשות היסטוריית התנועות מבקשות נתונים עדכניים ללא מטמון.
- הודעות שגיאה כוללות כעת את פירוט השגיאה שהשרת החזיר.
