# ערכת צבעים ירוקה חדשה

- נוספה ערכת צבעים ירוקה בהשראת אייקון משנת יוסף, עם התאמה מלאה לממשק ביום ובלילה.
- בחירת הערכה מחליפה גם את אייקון האפליקציה במסך הבית.
- נשמרו ערכות הכתום והסגול והבחירה נשמרת גם לאחר הפעלה מחדש.
# תיקון טעינת תמונות בהזמנה ובמצב איסוף

- תמונות המוצרים בהזמנה שלי ובמצב איסוף נטענות כעת גם לאחר שהשורה מקבלת תגית ניווט משלה.
- תוקן אימות בקשות התמונות ברקע כך שלא יתנגש בתגיות שמשמשות למיקוד ולניווט.
- נשמרו פעולות ההזמנה, סימון פריטים שנאספו והגדלת התמונות.
