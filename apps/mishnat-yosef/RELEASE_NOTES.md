# כניסה ל־TaskHub ללא שליחת מייל

- הכניסה למנהל המערכת מתבצעת כעת באמצעות סיסמת חשבון המנהל הקיים ב־Supabase, במקום קוד חד־פעמי למייל.
- האימות נשאר מול Supabase Auth, והאפליקציה מקבלת אסימונים רק לאחר בדיקת זהות חשבון המנהל המאושר.
- נדרשת הגדרה חד־פעמית של סיסמה לחשבון המנהל בלוח הבקרה של Supabase.
