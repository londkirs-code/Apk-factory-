# קיצורי מקשים ואיפוס תצוגה

- מקש 0 מאפס את גודל התצוגה ל־100%, מחזיר את פריסת המוצרים ל־3 עמודות ומעביר למצב יום.
- מקש 4 מקטין את גודל התצוגה ב־5% בכל לחיצה, עד 70%.
- מקש 6 מגדיל את גודל התצוגה ב־5% בכל לחיצה, עד 130%.
- מקש 5 מחליף את מספר עמודות המוצרים בסדר מעגלי: 1, 2, 3, 4, 5 ואז שוב 1.
- ההגדרות נשמרות ומוחלות מיד; קיצורי המקשים האחרים נשארים ללא שינוי.
