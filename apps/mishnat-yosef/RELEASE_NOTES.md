# כניסה ל־TaskHub ללא שליחת מייל

- הכניסה למנהל המערכת מתבצעת כעת באמצעות סיסמת חשבון המנהל הקיים ב־Supabase, במקום קוד חד־פעמי למייל.
- האימות נשאר מול Supabase Auth, והאפליקציה מקבלת אסימוני גישה ורענון רק לאחר בדיקת זהות חשבון המנהל המאושר.
- אין צורך בשליחת מייל לצורך כניסה. יש להגדיר מראש סיסמה לחשבון המנהל בלוח הבקרה של Supabase.
