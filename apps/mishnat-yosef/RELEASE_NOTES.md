# עדכון ידני אמין והגנה מפני התקנה לאחור

- כפתור „עדכון ידני עכשיו” מוצג בצבע הדגשה ברור ועקבי בכל מצבי המסך, ומרענן את פרטי הגרסה מול GitHub בכל לחיצה.
- כשנמצאת גרסה חדשה, מתחילה הורדה מאובטחת ואימות SHA-256; התקנת ה־APK דורשת את אישור Android.
- אם האפליקציה כבר מעודכנת, לא מתבצעת הורדה מיותרת.
- נחסמה התקנה של גרסה ישנה גם כאשר בדיקת הרשת נכשלת ונשאר מידע גרסה שמור במכשיר.
- אחרי בדיקה מוצלחת נשמרים במכשיר מספר הגרסה, שם הגרסה וחתימת הקובץ העדכניים.
