# תיקון פרטי המכירה במסך האיסוף

- מסך האיסוף משתמש בפרטי המכירה המלאים שמגיעים עם ההזמנה, במקום באובייקט חלקי שמחק את פרטי האיסוף.
- פרטי המכירה מרשומת ההיסטוריה משמשים כגיבוי ומשולבים עם תשובת פרטי ההזמנה, כדי לשמר יום ושעות איסוף, שם תחנה, כתובת והוראות הגעה.
- נשמרו מנגנוני סימון האיסוף, כמויות המוצרים ושאר פעולות ההזמנה.
