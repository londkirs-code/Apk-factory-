# בדיקת קפיצת המסך בהזמנות מהמטמון

- נוסף בהגדרות התצוגה מתג ניסיוני שמאפשר לדלג על בנייה מחדש של רשימת המוצרים אחרי לחיצה על + או − בהזמנות מהמטמון.
- כשהמתג מופעל, הכמות מתעדכנת בתווית בלבד, בלי לבנות מחדש את הרשימה ובלי להזיז את הגלילה או את מיקוד המקלדת.
- ברירת המחדל משאירה את ההתנהגות הקיימת; אפשר להפעיל ולכבות את הבדיקה בכל עת.
- הקוד והמתג מסומנים כהערה כזמניים, וייתכן שיימחקו אחרי שנזהה את מקור הקפיצה.
