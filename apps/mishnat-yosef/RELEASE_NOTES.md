# תיקון החלפת צבע לכל פסי ההזזה וההתקדמות

- פסי ההזזה בהגדרות התצוגה מתעדכנים מיד כשמחליפים בין ערכת הכתום לערכת הסגול, גם כשהם נמצאים בחלון קופץ פתוח.
- צבע הידית והפס הפעיל נלקח מהערכת הנושא הפעילה; מסילת הרקע מתאימה לצבעי הממשק.
- הוגדר כלל מרכזי אחד לכל רכיבי פסי ההזזה ומדדי ההתקדמות, עם רישום חלש של הרכיבים החיים כדי לעדכן גם חלונות נפרדים בלי להשאיר מסכים סגורים בזיכרון.
- השינוי נוגע לצביעה בלבד ואינו משנה את פעולת הפקדים.
