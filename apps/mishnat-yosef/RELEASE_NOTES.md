# Soft Edges + Glow לתמונות במצב לילה

- במצב לילה בלבד תמונות המוצרים מוקטנות ב־10% ומקבלות קצוות דוהים לשקוף והילה לבנה רכה, כדי לשלב אותן ברקע הכהה בלי מלבן לבן חד.
- במצב יום התמונות מצוירות בגודל המקורי וללא הילה או דהיית קצוות.
- השינוי משתמש במסכות ALPHA_8 עם מטמון משותף, ומכסה את תמונות המוצרים ברשימות, בסיכום ההזמנה, בפרטי מוצר, בנעילת ילדים ובתצוגה המוגדלת.
