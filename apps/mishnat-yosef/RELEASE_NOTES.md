# הסרת רקע לבן מתמונות מוצרים

- במצב לילה מוסר הרקע הלבן שמחובר לשולי תמונת המוצר, כדי שהתמונה תשתלב ברקע הכהה.
- הלבן שבתוך המוצר נשמר כאשר הוא מנותק מהרקע החיצוני.
- במצב יום מוצגת התמונה ללא אפקט הילה או צל; קובצי המקור בדיסק אינם משתנים.
- העיבוד כולל בדיקות הגנה ומחזיר את התמונה המקורית אם התוצאה נראית חשודה או אם העיבוד נכשל.
- השינוי חל במסכי המוצרים, סיכום ההזמנה, פרטי המוצר, נעילת הילדים והתצוגה המוגדלת דרך מנגנון טעינת התמונות המשותף.
