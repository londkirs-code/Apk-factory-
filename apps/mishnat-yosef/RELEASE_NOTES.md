# ביטול רענון עמוד בהזמנות

- המתג ״ביטול רענון עמוד בהזמנות״ נמצא בתפריט הפעולות בעמוד ההזמנה, ופועל גם בהזמנות פעילות וגם בהזמנות מהמטמון.
- כשהמתג מופעל, שינוי כמות מעדכן את הכמות ואת סרגל ״ההזמנה שלי״ בלי לרענן מחדש את שורות המוצרים.
- כשהמתג כבוי, התנהגות הרענון הרגילה נשמרת. אפשר להפעיל או לכבות בכל עת מתוך תפריט הפעולות.
